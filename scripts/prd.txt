# Overview  
COMP4702 Machine Learning Assignment - Build a fully-reproducible ML pipeline that predicts the swing-related target in assignTTSWING.csv. The project requires implementing three different model families (linear/baseline, tree-based ensemble, neural network), comprehensive evaluation, and a polished PDF report with version-controlled code and markdown documentation. All analysis must demonstrate understanding through detailed explanations, result discussions, and connections to COMP4702 course concepts from ML lecture notes.

# Core Features  
## Data Processing Pipeline
- Load and analyze assignTTSWING.csv dataset schema and basic statistics
- Visual EDA with pair-plots, correlation heat-maps, class distribution analysis
- Data cleaning: drop irrelevant/ID columns, handle missing values
- Feature scaling/normalization and optional PCA implementation
- Problem framing decision (classification vs regression)

## Three Model Implementation
- Baseline Linear/Logistic model with hyperparameter grid search
- Tree-based Ensemble (RF/XGBoost/LightGBM) with feature importance analysis
- Neural Network (MLP or 1-D CNN) with learning curve tracking
- Cross-validation and hyperparameter optimization for all models

## Evaluation and Comparison Framework
- Consolidated metrics table across all three models
- ROC/PR curves or residual plots as appropriate
- Statistical significance testing and cross-fold variance analysis
- Feature importance and error analysis documentation

## Documentation and Reporting System
- SCOPE.md for data cleaning and EDA decisions with detailed explanations
- Individual model_*.md files for each model family with comprehensive result analysis
- COMPARE.md for side-by-side comparison and final model selection
- Final ML_assignment.pdf report (no page limit) compiled from markdown sources
- All documentation must reference ML lecture notes and demonstrate understanding through detailed discussions

# Stakeholders
- COMP4702 course instructors and TAs for grading against specific rubric criteria
- Peer reviewers for code quality and reproducibility assessment
