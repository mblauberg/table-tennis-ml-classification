# Model Selection Justification

## Data Characteristics Driving Choices
- **Tabular Sensor Data**: 46 numerical features from accelerometer/gyroscope
- **High Dimensionality**: 51 features requiring careful selection and regularization
- **Class Imbalance**: 7.7% minority class requiring special handling
- **Mixed Scales**: Different sensor ranges requiring normalization
- **Potential Non-linearity**: Sensor interactions likely complex

## Course-Based Model Selection

### Logistic Regression (Baseline)
**Data Justification**: Linear relationships in sensor features, high dimensionality benefits from regularization, probabilistic output suitable for imbalanced classes
**Course Concepts**: Linear classification, MLE, regularization, feature scaling

### Random Forest (Advanced)
**Data Justification**: Sensor interactions likely non-linear, robust to outliers, built-in feature importance, handles class imbalance
**Course Concepts**: Ensemble learning, bagging, bias-variance tradeoff, overfitting prevention

### Support Vector Machine (Advanced)
**Data Justification**: Effective with high dimensions, kernel methods for non-linearity, margin maximization for clear separation
**Course Concepts**: Margin maximization, kernel trick, Lagrange multipliers, regularization
